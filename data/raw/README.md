# Dados públicos versionados

Esta pasta contém as fontes públicas necessárias para reproduzir os experimentos documentados. Elas foram mantidas no repositório por serem distribuídas sob licença CC BY 4.0. O arquivo de Dhaka é compactado e maior que os CSVs, mas permanece abaixo do limite de arquivos do GitHub e permite repetir também a validação externa negativa.

| Arquivo | Fonte original | Finalidade no projeto |
| --- | --- | --- |
| `laghouat_2022/Laghouat_2022_final.csv` | Mendeley Data, DOI [10.17632/4jdt83yy43.3](https://doi.org/10.17632/4jdt83yy43.3) | Desenvolvimento, seleção e teste final do monitor de perdas. |
| `zenodo_inverter_2023_2024/math_model_all_inverters_03.11.2023-25.06.2024.csv` | Zenodo, DOI [10.5281/zenodo.17775544](https://doi.org/10.5281/zenodo.17775544) | Avaliação complementar de estimação de potência. |
| `dhaka_2019_2020/Solar Dataset.zip` | Mendeley Data, DOI [10.17632/g6pxf8nnt6.2](https://doi.org/10.17632/g6pxf8nnt6.2) | Teste externo de transferibilidade com painéis limpo e exposto. |

Os checksums, as limitações metodológicas e a atribuição completa das fontes estão em [docs/dados.md](../../docs/dados.md). Não adicione dados operacionais, dados pessoais, arquivos derivados ou novas bases sem revisar licença, privacidade e necessidade metodológica.
